# ML_course
Упражнение 1

В директории data -- результаты предсказаний методом LOO при слепой кросс-валидации шестью ML-моделями:
rr - ридж-регрессия, ada - апаптивный бустинг, mlp - многослойный перцептрон)
Все расчеты были выполнены с помощью пакета scikit-learn.

Мнемоника названия директорий такая: сначала идет "noToxic_" (при обработке ингорируем и пропускаем его),
потом - сокращенное название противоракового лекарства, потом доза в наномолях на грамм,
потом ".csv_" (при обработке ингорируем и пропускаем его), потом - метод расчета.

В каждой из директорий нас интересует файл y_flowps_score.csv. Структура его данных в стоблцах такова:
"tmid_all" - код пациента (сase), при обработке префикс "tmid_all_" игнорируем и пропускаем,
"Y" - наблюдаемый в реале ответ на лекарство: 0 - не помогло (неответичик), 1 - помогло (ответчик),
"Y0" - пока ингорируем и пропускаем, "Y1" - слепое предсказание ответа для пациента этого номера в рамках данной модели.

Задание: найти и построить violin plots для следующих величин:

1) max_SN (макисмальная по всем значениям порога дискриминации theta чувствительность);
2) max_SP (макисмальная по всем значениям порога дискриминации theta специфичность);
3) max (SM + SP)/2;
4) AUC (не зависит от theta);
5) AUPR (не зависит от theta);
6) max_ACC;
7) max_MCC;
8) max_F1;
